## Udemy Full-Stack & Web3 Curriculum

| Technology / Topic | Core Concepts Covered | 
| ----- | ----- | 
| HTML 5 | Semantic markup, accessibility, forms, document structure | 
| CSS 3 | Custom properties, box model, selectors, modern layout techniques | 
| Flexbox & CSS Grid | Responsive design, alignment, grid templates, page architecture | 
| Bootstrap 5 | Utility classes, responsive containers, component design | 
| JavaScript (ES6+) | Modern syntax, promises, async/await, array methods, modules | 
| DOM Manipulation | Event handling, node navigation, programmatic element creation | 
| jQuery | Event handling, dynamic DOM operations, AJAX calls | 

| Technology / Topic | Core Concepts Covered | 
| ----- | ----- | 
| Node.js & NPM | Event driven architecture, package management, script automation | 
| Express.js | Route handling, custom middleware implementation, RESTful patterns | 
| EJS | Server side rendering, partials, template data passing | 
| REST APIs | HTTP requests methods, API endpoint structure, JSON processing | 
| SQL & PostgreSQL | Relational queries, table schemas, normalization, foreign keys | 
| Authentication | Password hashing, sessions, cookies, OAuth integration, JWT |
